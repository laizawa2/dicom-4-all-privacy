dicom-4-all-privacy

Privacy policy and terms of service for DICOM_4_ALL, an AI-powered technical assistant for DICOM standards, medical imaging interoperability, PACS, VNA, DICOMweb, HL7, FHIR, and IHE.

This repository hosts the pages through GitHub Pages. It contains no plugin code.

Plugin

The DICOM_4_ALL plugin for Claude is in a separate repository: https://github.com/laizawa2/dicom-4-all

Install in Claude Code:

/plugin marketplace add laizawa2/dicom-4-all
/plugin install dicom-4-all@dicom-4-all

In claude.ai or the Claude desktop app: Customize > Plugins > Add > Add marketplace, then enter laizawa2/dicom-4-all.

Important: remove all PHI before use

Do not submit identifiable patient or healthcare professional information. Before sharing DICOM headers, datasets, screenshots, or logs, remove all PHI, patient identifiers, physician identifiers, and any other information that could directly or indirectly identify an individual. Use synthetic or appropriately de-identified technical examples only.

DICOM_4_ALL does not provide medical diagnosis, treatment advice, patient-specific clinical interpretation, or clinical image interpretation.
